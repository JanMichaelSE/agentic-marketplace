# Interface-Design Guidance Moved

`codebase-design` owns the interface, seam, adapter, and deep-module guidance
used by TDD. When its optional companion plugin is installed, use
[SKILL.md](../../../software-architecture/skills/codebase-design/SKILL.md) and its
[alternative-design process](../../../software-architecture/skills/codebase-design/DESIGN-IT-TWICE.md).

For a standalone TDD session, agree on a caller-facing seam and test outcomes
through it; do not make interface redesign a prerequisite for a behavior test.
